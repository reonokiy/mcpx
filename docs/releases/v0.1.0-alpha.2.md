# mcpx v0.1.0-alpha.2

Native OAuth login and automatic refresh are now available.

```bash
mcpx auth login private
mcpx private echo --message hello
mcpx auth status private
mcpx auth logout private
```

Configure an HTTP server with `credential = "oauth"`, or use `--url ENDPOINT`.
Login uses the system browser, Authorization Code + PKCE S256 and a loopback
callback. The CLI discovers MCP protected-resource and OAuth/OIDC metadata,
supports pre-registered public clients (`--client-id ID`), CIMD and legacy DCR,
and binds code/token requests to the MCP resource and authorization issuer.

Credentials use the OS credential store by default. For headless hosts, explicitly
select `auth login ... --store file`; Unix files have mode 0600 and are atomically
replaced. Expiring tokens refresh automatically. Concurrent CLI processes share a
refresh lock and persist rotated refresh tokens. Logout removes local credentials
and asks the server to revoke them when supported. Failed tools are never replayed.
Use `--no-browser` for manual authorization and `--redirect-port PORT` for a
pre-registered/DCR callback; `0` selects an ephemeral port. Official CIMD uses port
48721. `--scope SCOPE` adds permissions.

## Multiple users

`mcpx --profile alice auth login private` and `mcpx --profile bob auth login private`
keep accounts separate. Resource and profile jointly identify persistent grants
and locks. `credential = "oauth:alice"` selects a profile in configuration.

Rust applications can use `OAuthCredentialProvider::from_grant(grant)` for private
in-memory OAuth state, or `for_profile(endpoint, account)` for persistent state.
Provider clones share refresh only within that identity. Different users use
independent Remote/QueuedRemote instances, schemas, handles and credential
snapshots. Clearing Alice's provider does not clear Bob's. The application controls
which authenticated user is allowed to select each profile.

Native Linux/macOS/Windows, Web/Component, standalone WASI and source archives are
built and uploaded by GitHub Actions. Interactive OAuth is native-only in this
alpha; browser and WASI hosts retain their credential-provider interfaces.
Rust crates are available as Git dependencies at tag `v0.1.0-alpha.2`.
