# mcpx v0.1.0-alpha.3

This release adds configuration profiles, local server management and clearer CLI help.

## Profiles and server management

```bash
mcpx --profile dev servers add context7 --url https://mcp.context7.com/mcp
mcpx profiles list
mcpx profiles use dev
mcpx servers list
mcpx context7 -h
mcpx context7 query-docs --help
```

Profiles own separate server namespaces and OAuth login state. Different profiles
can contain the same server alias. `profiles use NAME` saves `default_profile` in
the selected configuration; `--profile NAME` overrides it for one command.
Native configuration discovery searches the current directory and its parents
for the nearest `mcpx.toml`; `--config FILE` overrides discovery.

`servers add` supports HTTP endpoints and stdio programs, validates the result,
preserves comments and atomically writes the configuration. Duplicate aliases in
the same profile are rejected. Existing `[servers.*]` configurations remain
readable as the default profile and migrate to `[profiles.default.servers.*]`
when a server is added.

The CLI's `--profile` now selects both configuration and OAuth state. Applications
that previously used it only for OAuth should define the matching configuration
profile. OAuth tokens remain in the credential store, outside TOML files.

OAuth login now defaults to automatic credential storage: keyring first, then
private files if the keyring cannot be accessed. The CLI prints the file path;
Unix token files retain mode 0600. Explicit `--store keyring` remains strict.

For headless login, `auth login --no-browser` accepts a complete callback URL pasted
into the waiting terminal, alongside the loopback listener. Stale or unrelated
callbacks are rejected without consuming the current login transaction. State,
redirect and issuer validation remain enforced before token exchange.

## Help and development

Management commands use clap-generated subcommand help. Missing arguments and
invalid command syntax display contextual help as text. `mcpx SERVER -h` lists
that server's tools; `mcpx SERVER TOOL -h` shows tool parameters. Help discovery
does not execute business tools. Dynamic descriptions preserve paragraphs while
other terminal controls remain escaped.

A pinned mise development environment provides Rust 1.100.0, Node 24, Python 3.12,
Wasmtime and setup/build/check/test tasks. The library MSRV remains Rust 1.88.

Native Linux/macOS/Windows, Web/Component, standalone WASI and source archives are
built by GitHub Actions. Configuration writes and interactive OAuth require the
native CLI. This release includes a local Context7 configuration used to verify
real tool discovery and documentation queries.
