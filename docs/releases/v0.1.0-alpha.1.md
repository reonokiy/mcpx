# mcpx v0.1.0-alpha.1

First public test release of mcpx: discover MCP tools at runtime and call them from a CLI, a Rust library, or WebAssembly. Tool schemas come from the remote server; no tool-specific code generation is needed.

## Try it

- **Native CLI:** choose the archive matching Linux, macOS or Windows, extract it and run `mcpx --help`. The Linux x86_64 GNU build requires glibc 2.39+. The artifact name includes the actual Rust target triple.
- **WASI CLI:** extract `mcpx-v0.1.0-alpha.1-wasm32-wasip2.tar.gz`, then run `wasmtime run -S http mcpx.wasm --help`. This is the standalone CLI, with host-provided HTTP.
- **Browser / Component:** extract the `web` bundle, run `python3 -m http.server 8080 --bind 127.0.0.1` from its root and open `http://127.0.0.1:8080/examples/web-worker/`. The server must allow the browser origin through CORS. The bundle includes the JS modules, Wasm runtime, Worker example, typed WIT interface, raw Component and jco adapter.
- **Rust library:** use the Git dependency below, or extract the `source` archive and use `crates/mcpx` as a path dependency. Existing `Serialize` types, JSON, command strings and argv share runtime schema validation.

```toml
[dependencies]
mcpx = { git = "https://github.com/reonokiy/mcpx", tag = "v0.1.0-alpha.1", features = ["native", "command", "config"] }
```

Example CLI use:

```bash
mcpx --url https://your-server.example/mcp tools
mcpx --url https://your-server.example/mcp echo --message hello
mcpx --url https://your-server.example/mcp echo --args '{"message":"hello"}'
```

Native HTTP and stdio, schema-based CLI help/completion, typed arguments, JSON/SSE, cancellation and continuations are available. Web/Worker and native clients also provide opt-in bounded session renewal without replaying failed tool calls.

## Alpha scope

Public Rust crates are not yet published on crates.io; use the source workspace. APIs and the Component ABI are experimental. OAuth login, persisted catalogs, WASI automatic session renewal, and complete Schema CPU/allocator budgets remain future work. This release does not claim complete MCP conformance.

`SHA256SUMS` covers the downloadable archives. Binary/Web bundles include project and third-party license notices; `release.json` records its source commit and compiler.

Built and uploaded automatically by GitHub Actions when the version tag is pushed.
